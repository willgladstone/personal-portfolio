# Personal Portfolio

Personal Portfolio Website created with 11ty.

See [Demo](https://gla.dst.one)

## Deploy to Netlify:

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/willgladstone/personal-portfolio)

## Features

- Fully Customizable
- Semantic HTML
- Theming with TailwindCSS (Dark/Light)
- Accessible (WCAG AA)
- Self-Contained (no external resources)
- Search Engine Optimized

## Getting Started

- Run `npm start` for a development server and live reloading
- Run `npm run build` to generate a production build
